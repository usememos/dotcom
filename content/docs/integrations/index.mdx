Connect Memos to the tools you use to capture and work with notes. Use the API for scripts and applications, MCP for AI assistants, webhooks to react to memo events, or a separate Telegram integration to capture messages.

## Choose the question you need to answer

| If you want to know… | Start with… |
| --- | --- |
| How do I read or write memos from my own application? | [API Access](/docs/integrations/api-access) |
| How do I let an AI assistant work with my memos? | [MCP Server](/docs/integrations/mcp) |
| How do I capture a note from Telegram? | [Telegram Bot](/docs/integrations/telegram-bot) |
| How do I trigger another service when a memo changes? | [Webhooks](/docs/integrations/webhooks) |

API and MCP calls act with the permissions of the account behind the token. Create a separate token for each application so you can revoke its access independently. For webhook receivers, follow the signing and response requirements before processing events.

For request and response details, open the [API Reference](/docs/api) and choose the version that matches your instance; Latest tracks `main`. For instance-wide sign-in setup, see [Authentication](/docs/configuration/authentication).
