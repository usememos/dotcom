## Configuration layers

Runtime flags and `MEMOS_*` environment variables control server startup. Instance settings manage policies and services through the UI or API. From 26.10, [declarative configuration](/docs/configuration/declarative-configuration) files can manage identity providers, instance settings, and bootstrap administrators instead: Memos applies them at startup or with `memos config apply`, and managed resources are read-only in the app.

In Memos 0.31, the `ACCESS` instance setting selects public or private access independently of `MEMOS_INSTANCE_URL`. Set the URL to the canonical external HTTP(S) address, including for private instances behind a proxy. Manage access in instance settings or in [declarative configuration](/docs/configuration/declarative-configuration#access-policy).

For the installation itself, start with [Deploy](/docs/deploy). Once Memos is running, use [Admin](/docs/admin) for ongoing instance and account management, and [Reverse Proxy](/docs/deploy/reverse-proxy) for HTTPS and forwarded headers.
