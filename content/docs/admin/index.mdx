Active instance administrators can read and manage individual memos, including private and Space-only content. Collection listings still filter by audience, and administrators do not automatically become Space members. Review roles and membership together when deciding who needs access.

For server configuration and sign-in setup, continue to [Configuration](/docs/configuration). For creating and using a shared workspace, see [Spaces](/docs/usage/spaces).
