Capture a thought, find it again, and decide who can read or respond to it. These pages explain the individual Memos features you can combine into a daily practice, from writing and attachments to Views, Spaces, and sharing.

## Write and capture

<Cards>
  <Card title="Memos" href="/docs/usage/memos" icon="FileText">
    Create and edit notes, link related memos, pin important content, and choose placement and visibility.
  </Card>
  <Card title="Attachments" href="/docs/usage/attachments" icon="HardDrive">
    Add images and files to a memo, browse the attachment library, and review unused uploads.
  </Card>
  <Card title="Writing Markdown" href="/docs/usage/writing-markdown" icon="FileText">
    Format plain-text notes with headings, checklists, tables, code blocks, and links.
  </Card>
</Cards>

## Organize and find

<Cards>

  <Card title="Views" href="/docs/usage/views" icon="Filter">

## Choose the question you need to answer

| If you want to know… | Start with… |
| --- | --- |
| How do I write a note with a checklist or image? | [Memos](/docs/usage/memos), [Writing Markdown](/docs/usage/writing-markdown), and [Attachments](/docs/usage/attachments) |
| How do I return to the same set of related notes? | [Tags](/docs/usage/tags) and [Views](/docs/usage/views) |
| How do I find an older note or clear it from my timeline? | [Search & Archive](/docs/usage/search-archive) |
| How do I work with a group and control who can read a memo? | [Spaces](/docs/usage/spaces) and [Sharing](/docs/usage/sharing) |
| How do I join a discussion and keep track of replies? | [Reactions & Comments](/docs/usage/reactions-comments) and [Inbox](/docs/usage/inbox) |
| How do I connect SSO to the account I already use? | [Linked Identities](/docs/usage/linked-identities) |

Start with a few memos and add tags or Views when you have something you want to revisit. When collaborating, check placement and visibility separately: assigning a memo to a Space does not automatically make it visible to that Space's members.

To combine these capabilities into a complete, repeatable practice, explore [Guides](/docs/guides).
