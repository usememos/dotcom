# Memos product language

Canonical terms for Memos product copy and documentation.

## Language

**View / Views（视图）**:
A named, reusable set of Memo filter conditions that shows the Memos currently matching those conditions when opened. A View does not store Memo copies or represent a display layout such as a list or cards.

一组有名称、可重复使用的 Memo 筛选条件。打开视图时，展示当前满足条件的 Memo；视图不保存 Memo 副本，也不表示列表、卡片等展示布局。

_Avoid as product names_: Memo View(s), Saved View(s), Saved Memo View(s), Shortcut(s), Memo 视图, 已保存视图, 快捷方式.

**Save as view（保存为视图）**:
The action of saving filter conditions as a View. The resulting object is still called a View（视图）.
